## Projection and proof limits

`tool-order.jsonl.txt` retains original event order, commands, file-change paths and explicit visible messages. Generated numeric action links replace tool-item IDs. It omits full stdout echoes, thread/session/task identifiers, reasoning, usage and account/auth envelopes; original complete-stream SHA-256 values bind the immutable local originals. Raw fixture tracker logs contain only synthetic `example/flow` and fixture-owner identities, not a real account or credential. Hashes and host receipts attest retained bytes and launch declarations; they do not independently prove an honest launch, all hidden transient writes or production behavior.

The source exercise proves only these captured synthetic checkpoint-update/re-entry paths. It does not prove a complete implementation workflow, arbitrary distributed continuity, real production export/rollback or a deterministic enforcement sandbox. In `local-advance`, the trace creates, compares and removes a temporary `/tmp/export-proof-before-source-return.md` verification copy; a retained-state seal alone would miss that transient file. No substitute planning artifact or outcome experiment results from it. The lost-handoff case proves unknown/no-artifact handling with a context blocker, while the fully specified unknown-history case is separate.

Historical failures remain historical failures. The Markdown-backtick and apply/build corrections are observer-format/selection corrections, not replacement model outputs; prior source and report bytes were not edited or relabeled. The final source freeze and final round are the accepted evidence. No raw full host streams, copied built skills, project trees or whole Git states are published here.

Verify retained archive bytes from this directory with `shasum -a 256 -c SHA256SUMS`. Checksums cover every other final file; the checksum file does not hash itself.
