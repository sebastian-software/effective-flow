# Delivery branch

This is the machine-managed delivery branch. It carries the published skill, its user documentation, and the automation that maintains them — no source tree, no build, and no tests.

Source, developer documentation, and contributions live on [`develop`](https://github.com/sebastian-software/effective-flow/tree/develop).

Every file here is generated by the delivery step, so any edit made on this branch is overwritten by the next delivery. Do not implement here and do not open a pull request against this branch. Make the change on `develop` instead.

Guidance loaded from a surrounding checkout describes the source branch and does not apply to this one.
